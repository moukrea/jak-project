Grecharged-grass-poc = renderer-only 3D grass over the jak1 training level (Geyser Rock),
gated in Graphics Options > Recharged Settings > GRASS SETTINGS (nested sub-submenu; default ON;
OFF == byte-identical stock). All code in the pc/renderer layer, engine goal_src untouched.

Key files/knobs:
- `game/graphics/opengl_renderer/GrassRenderer.cpp` — whole-level CAMERA-INDEPENDENT static placement
  (the culling fix: no camera window, no move-rebuild, no distance re-grade → DROPPED=0). Placement is
  per-triangle barycentric over tfrag[0] + tie[0] tris whose texture `is_grass_ground` (STRICT exact
  set: tra-grass / bch-grassfringe / bch-leafyground-hang-2x1; rock/beach excluded). Knobs: `D_TARGET`
  150/m², `MAX_INSTANCES` 640k (× density-slider/100, clamp [0.5,2.5]), `GROUND_UPNESS` 0.50 (rejects
  >60° faces), `MAX_TRI_AREA` 300 (never hit; maxArea on training ~10 m²). Pool ≈ 864k pre-cull.
- OCCLUSION (hide grass under objects): XZ cell grid (`OCC_CELL_M` 0.5). POLISH#7 = clip to the VISIBLE
  above-ground FOOTPRINT: mark object verts only in the near-ground CONTACT BAND `[OCC_LO 0.05m, OCC_HI
  1.5m]` (NOT the old 8m full-model silhouette → that + a plain 3×3 dilation culled 46%/397k = an empty
  HALO ring). Then morphological CLOSING (dilate THEN erode) fills interior pinholes WITHOUT growing the
  boundary (no halo). Scans TIE (all geos) + SHRUB. NB: warp-gate button/scarecrows are dynamic MERC
  actors (process-drawable) — NO static verts, can't be occluded without engine hooks (deferred).
- LIGHTING (POLISH#7, owner's #1): grass must MATCH the ground brightness per-location. The ground
  renders as `texture*(todLuma/255)*2.0` (neutral at todLuma=128; verified tfrag3.frag/background_common,
  todLuma = 8-palette PackedTimeOfDay luma via PreloadedVertex.color_index). So each instance stores
  `gspare = clamp((rawLuma/255)*2.0, 0.35, 1.30)` — the ground's OWN absolute factor. POLISH#6's BUG:
  normalised to the grass-ground MEAN (baked_ref 82) + clamped [0.45,1.35] → every lit patch pinned the
  +1.35 ceiling = uniform flashy over-bright, no variation. grass.vert also luminance-matches col to the
  ground albedo `inst_gcol.rgb` then `col *= inst_gcol.w`. Objective proof: grass ON lum 93 vs stock
  ground 102 (0.91×, not brighter); lit 92 vs shaded 80.
- `grass.vert`/`.frag` — desktop source; Android `.android.vert/frag` AUTO-GENERATED by preprocess.py at
  build (edit only desktop source). Instance attribs: loc0 pos+h, loc1 yaw/tint/curve/phase, loc2
  gcol.rgb (ground albedo) + gcol.w (baked light). u_mode 0=near blade strip, 1=X-cross card.
- GOAL bridges (pc/ layer): `pc-set-recharged-grass!` toggle + `pc-set-jak-pos!` (trample) +
  `pc-set-jak-ledge!` (ledge-grab part). Default-ON in pckernel-impl.gc. Sliders: recharged_grass_near_dist
  30 / _card_dist 95 / _density 150 in gfx.h, read live in render().
