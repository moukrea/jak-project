Grecharged-grass-poc = renderer-only 3D grass over the jak1 training level (Geyser Rock),
gated in Graphics Options > Recharged Settings > RECHARGED GRASS (default ON; OFF == byte-identical
stock). All code in the pc/renderer layer, engine goal_src untouched.

Key files/knobs:
- `game/graphics/opengl_renderer/GrassRenderer.cpp` — whole-level CAMERA-INDEPENDENT static placement
  (the culling fix: no camera window, no move-rebuild, no distance re-grade → DROPPED=0). Tuning:
  `MAX_INSTANCES` (density lever — the uniform field is budget-clamped, so raising the ceiling raises
  density directly), `GROUND_UPNESS` (walkable-ground gate; 0.40 lets sloped/bumpy platforms qualify),
  `D_TARGET`, LOD band constants mirror grass.vert.
- `game/graphics/opengl_renderer/shaders/grass.vert` / `.frag` — desktop source; Android `.android.vert/frag`
  are AUTO-GENERATED by `shaders/preprocess.py` at build (edit only the desktop source).
- GOAL bridges: `pc-set-recharged-grass!` (toggle) + `pc-set-jak-pos!` (Jak `control trans` → trample).
  Default-ON at `goal_src/jak1/pc/pckernel-impl.gc:153`.

Build/verify loop: `.autoport/grass_fast_redeploy.sh` (libgk-only: x86 compile-check + android libgk +
APK + install + deploy_verify) then `.autoport/grass_moving_capture.sh` (ON/OFF A/B at the SAME spawn,
moving screenrecord + per-frame chunk DROPPED instrumentation, fps ON/OFF, restores default-ON,
force-stops). Push playtest builds: `gh release upload jak1-grass-poc <apk> --clobber -R moukrea/jak-builds`.
