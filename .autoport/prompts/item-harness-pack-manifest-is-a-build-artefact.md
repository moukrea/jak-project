# Le manifeste du pack d'assets est un produit du build, pas une source : il ne doit plus salir l'arbre à chaque build

## Defaut cite
- (aucun retour de l'owner enregistre sur cet item)

## Cause connue
Cree le 19/09 23:20 par le superviseur. FAITS : android/app/src/jak1/assets-slim/bundle/jak1_cgo.manifest.properties (et jak1_custom.manifest.properties) sont SUIVIS par git et REECRITS par gradle a chaque build (android/build_cgo_pack.sh:51 ; en-tete « Generated by android/build_cgo_pack.sh — do not edit »). CONSEQUENCES MESUREES le 18-19/09 : (1) des commits de bruit « manifeste de pack reecrit par gradle (aucun code de jeu) » ; (2) la porte de fermeture « arbre sale herite » a JETE l'essai 5 de hud-eco-gauge, porte VERTE sur l'appareil (23:12), pour ce seul fichier ; (3) l'annonce « build publie » prenait ce fichier pour du code de jeu (corrige par pathspec d'exclusion). Palliatif pose : les deux chemins sont inscrits a .autoport/.commit_quarantine.json (mis de cote, nommes, non bloquants). CIBLE : le manifeste n'est plus une source suivie — soit ecrit hors de l'arbre (dans build/ ou out/) et copie dans l'APK par gradle, soit gitignore avec un gabarit suivi ; l'APK doit contenir le MEME manifeste (version, file_count, raw_bytes) qu'avant. PORTE : `git ls-files` ne liste plus les deux manifestes ; un build complet laisse `git status --porcelain -- android` VIDE ; l'APK produit porte un manifeste avec les memes cles et un file_count identique au precedent ; la quarantaine peut alors etre videe de ces deux entrees (terme : entrees retirees).
