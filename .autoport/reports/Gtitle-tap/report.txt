(goal_src/jak1/levels/title/title-obs.gc:781 — UNCHANGED) sees a genuine edge:
same state transition, same sound, same menu.

- android/gk_android_main.cpp:2940-2966 — per-frame GOAL-thread publisher computes
  g_on_title_start: true only when *target*'s current state NAME is
  `target-title-wait` (process.state @ deftype 56, state.name @ deftype 4, read at
  deftype-4 — same idiom as the Gwarp-dpad walker) AND no menu is up (in_menu
  false). This is the exact state whose :trans checks START, so the scope is
  precisely the press-start screen.
- android/gk_android_main.cpp:7048-7067 — JNI Java_..._isOnTitleStart (atomic read)
  and Java_..._onTitleTap (re-checks the flag, so a stale tap can never inject).
- android/android_input_audio.cpp:584-588,603-609 + android_input_audio.h:65-70 —
  trigger_title_start_pulse() holds button0 bit 3 (kPs2StartBit) for 4
  get_cpad_state polls: clean rising edge then release, OR-merged with the
  overlay/gamepad/inject producers. Logs marker "GTT-TAP".
- android/app/.../NativeGk.java:135-149 — the two new natives.
- android/app/.../TouchOverlayView.java:504-513 — top of onPointerDown: ANY tap
  (any screen position, even over overlay controls) while isOnTitleStart() fires
  onTitleTap(); falls through so overlay controls still actuate normally.
