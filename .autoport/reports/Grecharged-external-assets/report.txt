== THE SPLIT (design) ==============================================================
- ARCHIVE = pure arch-independent extracted-original data (never changes across releases):
  iso data files (STR/VAG/TXT/VIS/SBK/MUS + ALL VAGWAD languages), fr3 texture packs,
  recharged_assets HUD pngs. Producer: scripts/package_game_assets.sh (python-zipfile, zip64).
  Archive artifacts produced at path out/artifacts/ (archive path reported per game below):
    jak1_assets.zip  975,816,002 B (331 files, VAGWAD ENG,FRE,GER,ITA,JAP,SPA)
    jak2_assets.zip  3,546,954,952 B (613 files, VAGWAD ENG,FRE,GER,ITA,JAP,KOR,SPA)
  jak2: ALL 7 language VAGWADs restored — this REPLACES the AGP-2GB-cap workaround that
  dropped non-English audio (FR audio back). The runtime ENG-fallback in iso_api.cpp is KEPT
  as the mandate's graceful-degradation path for genuinely absent language files.
- BINARY carries the per-arch compiled *.CGO/*.DGO ("CGO pack") + android-text COMMON.TXT
  overrides: android/build_cgo_pack.sh -> APK asset bundle/<game>_cgo.zip
  (jak1: 28 code files, 111.6MB; jak2: 151 code files, 290.7MB; content-versioned,
  arm64!=x86 KERNEL.CGO hard gate). Compiled code riding the binary kills the mixed-build
  SIGILL class (CGOs always match libgk) — that's why CGOs are NOT in the data archive.
  fake_iso gained an overlay-dir scan (overlay first, dup filenames skipped) to merge the two.
- APK: slim is the DEFAULT (assets-bundled only via -PbundledIso=true). jak1 APK size
  1,197,179,428 B before -> 164,523,835 B after (157MB; libgk 106MB + cgo pack + dex).
  x86: scripts/package_game_release.sh emits gk + data/{x86 CGO-DGO,shaders,game assets,
  goal_src/user} as the binary tarball artifact next to the shared assets archive.

== LAYOUT + RUNTIME (game reads a user-chosen location) ============================
<chosen>/jak_1/assets/{iso,fr3,recharged_assets}  <- archive decompressed here (jak_2/jak_3 same)
<chosen>/jak_1/saves/                              <- memcard banks + settings/ configs beside saves
<chosen>/jak_1/custom_assets/texture_replacements/ <- player texture packs
gk: new --game-root <chosen>/jak_N + --iso-overlay <cgo dir> flags (shared x86+Android);
FileUtil routes iso/fr3/recharged/custom_assets + memcard/settings/misc/screenshots/features
under the root when set; UNSET = byte-identical legacy behavior (dev flow regression-tested).

== FIRST-BOOT PROMPT + PERSISTENCE =================================================
- x86: resolution = --game-root flag > pointer file <config>/asset-root.txt > legacy repo/data
  dir (must hold non-CGO data files, so a release binary pack still prompts) > stdin prompt.
  TTY prompt accepts the chosen folder and persists it; non-TTY prints a clear --game-root
  error and exits 1. Re-prompt happens when the pointer target goes invalid (try_accept fails).
- Android: LoaderActivity chooser screen (touch + D-pad): CHOOSE ASSETS FOLDER (SAF
  ACTION_OPEN_DOCUMENT_TREE picker, tree-URI converted to a real path), TYPE PATH MANUALLY
  (dialog), USE INTERNAL ASSETS (existing installs). Choice persisted in SharedPreferences
  + mirrored to files/asset_root.txt; MainActivity re-validates every boot and bounces back
  to the chooser when the root goes invalid (re-prompt proven by design + banner path).
