WHAT THE MENU IS
  The "main menu" the player sees after the title flythrough is the `progress`
  process opened on (progress-screen title) — title-obs.gc:760 calls
  (activate-progress *dproc* (progress-screen title)) on START. Its UI texture/
  sprite ASSETS (the elements the owner reports "bunched toward center") are the
  `particles[]` HUD sprites (left/right side panels + ring/tint backdrop) laid out
  by progress.gc::adjust-sprites, and the `icons[]` eco/fuel-cell merc icons laid
  out by progress.gc::adjust-icons.

HOW PLACEMENT WORKS (so the dumped numbers are interpretable)
  - Each HUD sprite's on-screen horizontal position is its particle pos.x, a GS
    offset from screen-centre (user-hvdf.x = (int)pos.x + 2048).
  - The sprite3_3d.vert shader maps that to NDC with NDC.x = pos.x / 256.0
    (sprite3_3d.vert:160,165) — a FIXED /256, with NO framebuffer/aspect term.
    x-pix is the constant 256 (math-camera.gc:241), never aspect-scaled. So a
    sprite at pos.x = -220 sits at NDC -0.86 (7% from the left edge) at ANY
    aspect/resolution. => "bunched toward centre" can ONLY arise if pos.x itself
    is computed smaller (closer to 0) — i.e. a GOAL-side value, never the renderer.
  - The float aspect feeds aspect-ratio-scale (= aspect/4:3). At 2400x1080 (20:9)
    that is 2.2222/1.3333 = 1.6666. It scales sprite SIZE (sprite.gc:470, *= when
    not use-vis?), NOT sprite position.

METHOD
  x86: goalc listener (lt)+(build-game); (set-aspect! *pc-settings* 20 9) forces
       the device-matching 20:9 float aspect (aspect-ratio-scale 1.6666); the menu
       is opened with a REAL START press (xfocus_tap 28); each frame adjust-sprites'
       runtime fields are read over the listener. The PRISTINE original v0.3.3
       (/home/emeric/code/jak-original-v033, c4bc4d3ff) is read the SAME way and is
       NEVER instrumented (.autoport/gold stays byte-clean).
  device: a TEMPORARY GMENU-DUMP block in adjust-sprites (plain GOAL (format 0 ...)
       -> GK_STDOUT logcat; pure read-only no-op, REMOVED after measuring) emitted
       the same fields; consistent HEAD arm64 set built+deployed; menu opened via
       cpad_inject "start"; harvested from logcat. eae4df44, native panel 2400x1080.
