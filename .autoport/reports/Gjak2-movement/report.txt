== ROOT CAUSE NAMED: which stage of the move pipeline died, and why arm64 ==

The stage that died is the collision RESPONSE/RESOLVE stage of the mover — exactly diagnosis
lead 1 — but by NOOP, not by garbage codegen:

 (method 9 collide-cache-prim) = resolve-moving-sphere-tri and
 (method 10 collide-cache-prim) = resolve-moving-sphere-sphere
 (defmethod-mips2c, collide-cache.gc:817/819) are the ONLY resolve stage of the jak2 target
 mover. They were among the 14 names left DEFAULT-OFF (shared noop) by Gjak2-ingame's
 boot-crash quarantine. The noop returns 0 and writes nothing, and every consumer reads the
 float return with (>= f0 0.0):
   - step-collison! (collide-shape.gc:1093, per-prim loop :1111-1123): 0.0 = "hit at travel
     fraction 0.0" -> best-dist=0 -> reaction branch, moved fraction 0, retry loop; the
     no-hit translation branch move-by-vector! (:1182) is NEVER reached => every frame's
     displacement cancelled => Jak GLUED. Chain: target-post (logic-target.gc:2603) ->
     fill-cache-integrate-and-collide (:2524 / collide-shape.gc:1939) -> integrate-and-collide!
     (:1224) -> step-collison!.
   - find-ground (collide-shape.gc:1682) -> probe-using-line-sphere (collide-cache.gc:738):
     0.0 passes (>= f0-0 0.0) => phantom "ground found", then snaps gspot-pos/gspot-normal
     from the stack collide-tri-result (:1704-1705) that the noop NEVER WROTE => garbage
     constant normal fed to the slope/align code every frame => the constant one-direction
     DRIFT the owner saw.
 Movement ANIMATIONS are computed in the joint/anim pipeline independent of the collide
 result — which is why inputs visibly "arrived" while the character never translated.

Why the prior phase missed it: its "Jak WALKS" evidence was audited this phase and falsified —
run2/run3 injection held the analog sticks dead-neutral (every F1D-INJECT line: lx=ly=127,
D-pad bits only) and the video shows only camera creep; jak2 locomotion is analog-driven, so
translation was never actually tested. The owner's report was the first real analog test.
