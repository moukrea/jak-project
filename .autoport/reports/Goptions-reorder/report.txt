2. "PS2 Options" -> "Advanced settings" RENAME
================================================================================
"PS2 Options" no longer appears; it is renamed/relabelled to "ADVANCED SETTINGS" via the existing
name-override mechanism (all-caps, matching the other name-override menu labels the port added,
because the jak1 menu font only maps uppercase ASCII). The submenu contents (gfx-ps2-options) are
UNCHANGED. Implementation: the menu/button draw case in progress-pc.gc (draw-options) now honors
name-override (falls back to the localized name for every other menu row, so nothing else changes);
the Advanced-settings row gets name-override = *advanced-settings-label* "ADVANCED SETTINGS" in
init-game-options. Device screencap 06 shows "ADVANCED SETTINGS" (highlighted) after MSAA; the string
"PS2 Options" is gone (removed/renamed, no longer appears).

================================================================================
3. Min Target FPS HIDDEN when Dynamic Render Scale is OFF
================================================================================
Min Target FPS is only relevant when Dynamic Render Scale is ON. It is now HIDDEN (truly removed from
the visible list, not merely greyed) when Dynamic Render Scale is OFF, and shown when ON. The progress
renderer keys everything off (length options) and has no per-item grey-vs-hide distinction, so the row
is shown/hidden by mutating the live array length on the Dynamic toggle's on-change
(apply-dynamic-rs-menu-mode! -> graphic-options-set-mtf-visible!, idempotent; the arrays are
re-canonicalized to full at init before index-wiring). Dynamic OFF => Min Target FPS hidden.

Device proof (screencaps):
  02-graphics-ON.png  (Dynamic ON default):  Aspect Ratio, Game Resolution, DYNAMIC RENDER SCALE: ON,
     MIN RENDER SCALE, MIN TARGET FPS (VISIBLE), FPS COUNTER: OFF ...
  03-graphics-OFF-mtf-hidden.png (Dynamic toggled OFF): Aspect Ratio, Game Resolution,
     DYNAMIC RENDER SCALE: OFF, RENDER SCALE, FPS COUNTER: OFF, V-SYNC: ON  -> MIN TARGET FPS is GONE.
Toggling Dynamic Render Scale ON/OFF shows/hides Min Target FPS (off => hide). The slider row also
relabels MIN RENDER SCALE <-> RENDER SCALE with the toggle.
