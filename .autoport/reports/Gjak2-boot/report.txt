4. jak2-SPECIFIC arm64 FIX (translation layer only; bug class)
------------------------------------------------------------------------
game/kernel/jak2/klink.cpp — ARM64 KLINK RETROFIT (bug class: arm64 link
relocation stomping instruction words). jak2's four relocation functions
(cross_seg_dist_link_v3, ptr_link_v3, typelink_v3, symlink_v3) did raw x86 int32
stores that STOMPED the arm64 ADRP/ADD/LDR/STR immediate-carrying instruction
words the arm64 backend emits -> executing linked code SIGILL'd at a garbage pc.
jak1's klink was retrofitted (during its A-phase arm64 bring-up) to call the
shared klink_arm64_patch_pc_rel (game/kernel/common/klink.cpp) before the raw
store, keeping the raw store as the kNotInstr fallback; jak2's was never given
that retrofit. Mirrored jak1's pattern into all four jak2 functions, preserving
jak2's own sentinels (DebugSegment cross-seg null case; LINK_SYM_NO_OFFSET_FLAG).
x86-SAFE: the dispatcher returns kNotInstr on x86 slots -> raw store -> x86 jak2
oracle UNREGRESSED (still 483 link finish + kernel: machine started).
