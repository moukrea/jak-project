========================================================================
1. THE ROOT CAUSE (the white wash / frozen sky / stale frames)
========================================================================
goal_src/jak2/engine/gfx/foreground/shadow-cpu.gc:704:
    (set! (-> s3-1 base) (shadow-execute ... (-> s3-1 base)))
`shadow-execute` is mips2c. On Android it resolved to the shared arm64 noop (returns 0), so
whenever a shadow bucket had casters, the frame's global-buf base was set to 0. Every packet
built afterwards that frame — the BUCKET_2 vis/fog packet, camera data, the sky/clouds
texture-anim input — was appended into the low-EE dead zone (ee+0x12c0 band), and the bucket
chain got a low NEXT tag. The A42 chain-precopy guard (correctly) quarantined those chains and
re-presented the last good one: ~83% of title frames (6000 skips / 7260 frames) were STALE.
Consequences, all from this one defect:
  * clouds frozen (SkyInput.times pinned at 990/1005/1100 while the GOAL accumulator advanced
    — the consumed packet was a stale re-present),
  * searchlight cones flooding the camera white (stale emissive/pose data as the flythrough
    camera flew through a dwelling beam — bisect-proven: skip=merc => perfect night scene),
  * missing per-frame content (device drew 11 merc models vs x86's 28).
Forensics chain: prop-driven bucket-family mute bisect (debug.opengoal.vis.skip) -> plain-merc
family -> GJ2VIS-CLOCK/CLOCK2 state dumps x86-vs-device (all GOAL clocks tick; falsified the
frozen-clock hypothesis) -> GJ2VIS-GBUF (global-buf cursor intermittently in low memory) ->
Android low-memory PROT_NONE tripwire (desktop parity; debug.opengoal.lowprot=1) -> SIGSEGV at
the writer: STR of a qwc=6 cnt dma-tag to ee+0 -> GK-DIAG CODE window byte-matched to GAME.CGO
object #205 `shadow-cpu` -> shadow-dma-end -> the :704 base store.
FIX (game/mips2c/mips2c_table_jak1_arm64.cpp): un-noop the jak2 shadow-cpu mips2c family (all
16 functions — shadow-execute jalrs every sibling by name, so partial sets re-noop geometry).
Audited per the established checklist: zero integer div/mod (no IDIV/R8 hazard), all three s7
compares are symbol/boolean idioms (no upper-32 gpr_addr misfire), scratchpad via the proven
fake_scratchpad_data idiom, blerc DMA already bounds-guarded, external callees plain GOAL FFI.
Kill switch: setprop debug.opengoal.jak2.noshadowcpu 1 (relaunch-toggleable).
VERIFIED after fix: A42-CHAIN-PRECOPY count 0 (was ~6000), sky t advancing every sample,
GBUF cursors always in-buffer, 17 merc models drawn (jakb, daxter-highres, hud-ring now
present), crash-free 330s + ~7min soaks, PID stable.
