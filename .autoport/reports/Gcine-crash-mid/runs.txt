The owner's non-deterministic mid-cinematic crash is the merc/DMA blend-shape

  VICTIM : return-from-thread-dead (gkernel.gc:451), the per-process return
           TRAMPOLINE at GOAL 0x18aee4 (+ next word 0x18aee8). Pure kernel
           asm-func code in the protected band [0x18ae84,0x1912b4).
  WRITER : the intro-cinematic merc/keg blend-shape draw (GOAL pc resolves to
           vector-float*! / keg-post) issues an arm64 DOUBLE-EE-BASE store through
           a CORRUPT low base pointer; the CPU store faults in the [2*EE_base,..)
           window and handle_double_ee_base_fault "completes" it onto
           EE_base+0x18aee4 — i.e. the fault handler itself is the proximate
           writer that zeroes the trampoline. PROVEN: the ONLY DBLEE corrected
           store targets observed are 0x7f0018aee4 / 0x7f0018aee8 (sig=4/11 class).
  Why store-side telemetry was blind: the original CPU store faults at a DIFFERENT
           address (2*EE_base+...) and the corrupting write happens INSIDE the
           signal handler — invisible to the mips2c store band AND to an mprotect
           page tripwire (arming it RO on 0x18aee4's page gave hits=0 and a SILENT
           death at the stomp frame: a write to the RO page from within the
           handler faults recursively). This is the A38-blind-to-DMA class, here
           pinned to the DBLEE completion path.
  Owner escape (the rare uncaught crash): the 16-byte handler write zeroes the
           trampoline while the kernel-dispatch thread RETs into it; a partially
           written word that decodes to a valid-but-wrong branch/load escapes the
           in-band SIGILL repair and dies at a wild address — non-deterministic.

================================================================================
FIX — handle_double_ee_base_fault DROPS any completed store whose corrected target
intersects the kernel asm-func code band [0x18ae84,0x1912b4). Kernel code is never
a legit GOAL store target, so the double-EE-based value is garbage; dropping it
prevents the trampoline corruption AT THE SOURCE, race-free. (android/gk_android_main.cpp)
