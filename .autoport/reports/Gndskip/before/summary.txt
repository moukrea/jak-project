INJECT MECHANISM NOTE (important):
  The documented `run-as ... sh -c 'cat > files/cpad_inject'` redirect FAILS on this
  device: the redirect target is opened by the ADB-side sh at cwd '/' (Permission
  denied / wrong path). Working method = `printf 'start' | run-as org.opengoal.gk.jak1
  tee /data/user/0/org.opengoal.gk.jak1/files/cpad_inject`. The watcher does NOT
  truncate the file (it treats contents as HELD button state), so a momentary press =
  write 'start', hold ~0.6s, then write empty to release. Logcat 'F1D-INJECT applied:
  button0=0x0008 (raw=start)' confirms the START bit (bit 3) reached GOAL.
