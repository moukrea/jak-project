ITEM 5 — RIFT-GATE GLOW too bright pre-metalheads   [FIX LANDED + beat frame captured; owner calibrates]
ROOT CAUSE: GlowRenderer::blit_depth (GlowRenderer.cpp:539) reformatted the probe depth texture to unsized
GL_DEPTH_COMPONENT while the FBO attachment + main framebuffer are GL_DEPTH24_STENCIL8 -> ES 3.0 depth-blit
format mismatch fails on Adreno -> occlusion probe always passes -> discard_flag ~= 1 -> glows over-bright.
This is an arm64/GLES-ONLY rendering bug: x86 GL already accepted the blit, so the game-side glow size/interp
inputs are identical on both (the divergence was purely the failed GLES depth copy, not a glow-input value).
FIX (glue): sized GL_DEPTH24_STENCIL8 reformat (matches init + main FB) so the GLES depth blit succeeds and
the probe occludes correctly. Visually a no-op on x86.
