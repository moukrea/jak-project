             set, ONLY for geo==0 (the base LOD) so each proto appears once per
             tie tree. Line format:
               [tie-census] level=<debug_name> geo=0 proto=<name> \
                            instances=<n> stiffness=<f> wind=<0/1>

             classifier the extractor uses for the wind draw set:
               extract_tie.cpp:2583  bool using_wind = proto.stiffness != 0.f;
             (jak1 keeps wind; on jak2 using_wind is force-disabled.)
  Run      : TIE_CENSUS=1 build/decompiler/decompiler \
               decompiler/config/jak1/jak1_config.jsonc iso_data \
               /tmp/tie_census_out --version ntsc_v1 --disable-ansi
             FULL extraction (levels_extract already true, decompile_code false)
             so texture/tpage lookups are complete. Output went to a TEMP dir;
             out/jak1 (shipped fr3s) was NOT touched.
  Level id : 'level=' is the extractor debug_name (DGO + tie-tree index). A DGO
             can hold several tie trees:
               BEA.DGO-2-tie             = beach   (single tie tree)
               VI1.DGO-2/3/4-tie         = village1 (THREE tie trees:
                                            -2 = main exterior/structures,
                                            -3 = interiors/props,
                                            -4 = far/LOD ring incl. palms+trees)
