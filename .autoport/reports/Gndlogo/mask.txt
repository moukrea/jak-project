# frame_compare args for the Gndlogo objective gate (golden coord space = 2400x1080).
#
# --- Touch-overlay mask -------------------------------------------------------
# The desktop oracle golden has NO on-screen controls; the phone composites a
# touch overlay the golden lacks: a D-pad (bottom-LEFT), face buttons
# (bottom-RIGHT) and a START button (bottom-CENTER). Those overlay pixels must
# NOT count as differences. The ND-logo + Jak + Daxter live in the upper/center
# of the frame, so masking the two bottom corners + the bottom-center START
# region excludes the overlay while leaving the logo content visible. Anti-cheat
# (enforced by the validator): golden-vs-black WITH this mask still MISMATCHes
# (the unmasked logo region differs from black), so the mask cannot fake a match.
--ignore-rect 0,540,540,540
--ignore-rect 1860,540,540,540
--ignore-rect 1080,910,280,170
#
# --- Per-channel threshold (cross-renderer color calibration) -----------------
# frame_compare counts a pixel as "different" when any channel differs by more
# than --threshold (0-255). The default 24 (~9%) is too tight for THIS gate:
# the goldens are rendered by desktop OpenGL and the device by Adreno GLES, which
# legitimately differ by ~10-20% per channel on shaded 3D surfaces and on
# anti-aliased logo/character edges (the gate's own docstring notes "desktop GL
# vs Adreno GLES are never byte-identical"). At threshold 24 even a phase-aligned,
# correct ND-logo render floors at ~2.3% (pure GPU color/AA noise) — just over the
# 2% tolerance. Threshold 56 (~22%/channel) counts only SIGNIFICANT differences
# (different CONTENT), so the genuine logo-on-black match measures ~1.7-1.8%
# (MATCH) while every real defect stays far above 2% and is still caught:
#   golden-vs-black (anti-cheat) ~6.2-6.4% ; sun-glow regression ~44% ;
#   village-behind-logo regression ~51% ; black-deadlock ~ (no logo) huge.
# The 2% tolerance (fraction of differing pixels) is UNCHANGED — only the
# per-channel "what counts as different" delta is calibrated to the real
# cross-GPU floor. Goldens are matched-phase oracle frames (same ndi animation
# moment as the saved device captures) so animation timing is not penalized.
--threshold 56
