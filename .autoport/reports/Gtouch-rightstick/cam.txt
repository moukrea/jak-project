1. MODEL — anchor + deflection (FLOATING, INVISIBLE), NOT a frame-delta drag
------------------------------------------------------------------------------
The right 3/4 of the screen (x >= camRegionLeft = 0.45*W), on any touch that
MISSES every button, is a floating invisible virtual stick:

  * touch-DOWN  -> ANCHOR the stick at the touch-down point and start at neutral:
      onPointerDown(): t.anchorX = x; t.anchorY = y;
                       NativeGk.onPadAxis(RIGHTX, 0); onPadAxis(RIGHTY, 0);
      log: "overlay-actuate: camera anchor (x=..,y=..) -> floating invisible
            RIGHTX/RIGHTY stick (deflection = cur - anchor, sustained while held)"

  * touch-MOVE  -> the camera axis = the DEFLECTION = (current finger - anchor),
                   clamped to camMaxRadius() and normalized to +/-AXIS_MAX:
      onPointerMove() KIND_CAMERA:
        int[] rv = camDeflection(x - t.anchorX, y - t.anchorY, camMaxRadius());
        NativeGk.onPadAxis(RIGHTX, rv[0]); NativeGk.onPadAxis(RIGHTY, rv[1]);

      static int[] camDeflection(float dx, float dy, float maxR) {
        float dead = maxR * CAM_DEADZONE_FRAC;           // 0.12*maxR
        float d = (float) Math.hypot(dx, dy);
        if (d < dead) return {0, 0};
        float ox = dx, oy = dy;
        if (d > maxR) { ox = dx/d*maxR; oy = dy/d*maxR; } // clamp to radius
        int vx = clampAxis((int)(ox / maxR * AXIS_MAX));  // normalize [-1,1]
        int vy = clampAxis((int)(oy / maxR * AXIS_MAX));
        return {vx, vy};
      }
      camMaxRadius() = max(60, getHeight() * CAM_RADIUS_FRAC=0.16)

  * touch-UP/CANCEL -> the stick disappears; RIGHTX/RIGHTY return to 0:
      releaseTouch() KIND_CAMERA: onPadAxis(RIGHTX, 0); onPadAxis(RIGHTY, 0);
      log: "overlay-actuate: camera release -> onPadAxis(RIGHTX) value=0,
            onPadAxis(RIGHTY) value=0 (neutral)"

Because the move handler reads the CURRENT offset (cur - anchor) and NOT a
frame-to-frame delta (cur - last), holding the finger deflected keeps injecting
the SAME value every event -> a SUSTAINED pan. It does NOT decay to neutral when
the finger stops, which is exactly the difference from the old mouse-drag delta.

NATIVE PATH (unchanged, byte-equivalent to a physical right stick):
  NativeGk.onPadAxis(RIGHTX=2/RIGHTY=3,v) -> JNI Java_..._onPadAxis
  (gk_android_main.cpp:6023) -> android_input_audio::on_pad_axis
  (android_input_audio.cpp:544) -> g_stick_rx/ry.store(sdl_axis_to_ps2(v)) ->
  get_cpad_state picks injected rx/ry -> PS2 cpad right-stick -> GOAL camera.
