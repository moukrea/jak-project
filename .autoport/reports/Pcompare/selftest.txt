Phase Pcompare — objective pixel-compare gate SELF-TEST
========================================================
Tool:   .autoport/lib/frame_compare.py  (PIL-based, no numpy)
Metric: fraction of pixels whose per-channel delta exceeds threshold=24/255,
        after resizing the candidate to the golden's resolution.
        MATCH = diff_frac <= tolerance (default 0.02), else MISMATCH.
        (RMSE over all channels is also reported for context.)
Goldens are 1280x720 PNGs captured from the pristine upstream desktop build
(/home/emeric/code/jak-original-v033 @ c4bc4d3ff). Note: goldens carry an alpha
channel; the tool flattens to RGB before comparing, so alpha never skews the
score.

Invocation contract (matches what the validator exercises):
  python3 frame_compare.py GOLDEN CANDIDATE        -> exit 0 MATCH / exit 1 MISMATCH
Exit code depends ONLY on the metric verdict; writing the diff image can never
flip it (diff write is best-effort, wrapped, and falls back to a temp path).
