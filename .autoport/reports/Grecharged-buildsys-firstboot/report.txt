== (3) settings.ini INI bridge (risk R4) ==
GOAL pc-settings stays the single source of truth; only the serialization changed. The proven
s-expr reader/writer machinery in pckernel-common.gc (SHARED into jak1/jak2/jak3) was converted to
INI: [settings] + version = #x... + one `key = value...` line per setting, sections [secrets] /
[music] (jak2: [stats.kill-stats.<enemy>] per-enemy sections) emitted after plain keys; write-through
persistence parsed at boot, version-gated. jak2/jak3 overrides converted the same way; all three
games compile (goalc make-group engine: 343/447/472 targets).
Two real bugs were found by testing and fixed (not shipped broken):
  (a) file-stream-get-next-char clobbers *pc-temp-string* (it scratches raw stream bytes over the
      shared temp buffer), destroying the just-read key before dispatch -> the reader now consumes
      `=` and `]` via single-byte getc reads (pckernel-common.gc doini-keys + section loop).
  (b) Android bound pc-filepath-exists?/pc-mkdir-file-path to the a17_pc_default 0-return stub; 0 is
      not #f to a compiled GOAL (if) test, so every path "existed" and first boot never committed
      defaults (this also explains why the OLD pc-settings.gc only ever appeared after a menu commit
      on device). Real stat()/mkdir-p bodies now bound for jak1+jak2 (gk_android_main.cpp).
