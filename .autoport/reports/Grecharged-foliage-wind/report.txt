# Grecharged-foliage-wind — jak1 foliage wind wobble (Recharged, gated)

RESULT: PASS — jak1 palm leaves (TIE wind shear boost 3.0x) + shrubs (per-plant vertex-shader sway) react to a light breeze behind a new top-level "FOLIAGE WIND" toggle in the Recharged Settings submenu, default OFF == stock render (byte-identical arithmetic when OFF), proven on the Redmi with matched-pose OFF/ON screenrecords + motion-grid metrics + fps perf at two vantages. Owner play-test is the final gate.

## Owner request (2026-07-09)
Palm leaves + shrubs are completely static; add light wind wobble/sway ("légère brise") so the world looks less frozen; extra toggle in Recharged Settings.

## What was built (commit 4a2d5c76e)

### Toggle (Recharged Settings, default OFF)
- New pc-setting `recharged-foliage-wind?` (default #f) with key-based persistence (pckernel.gc read/write arms) and a per-frame update-to-os push -> `pc-set-foliage-wind!` -> `Gfx::g_global_settings.recharged_foliage_wind` (kmachine.cpp, logs on change).
- Menu row "FOLIAGE WIND" on the TOP-LEVEL Recharged Settings page (row 4, before Back) — the owner asked for a toggle "dans les Recharged Settings", and the nested Grass page is already at PROGRESS_PC_PAGE_HEIGHT (7 rows). The ENHANCED MODELS dynamic collapse was updated (length 6 -> 5, shifts FOLIAGE WIND + Back up) with length-aware wiring so re-inits stay correct in both states.
- OFF == stock: shrub shader sway branch is `if (u_wind_strength > 0.0)` with strength forced 0.0 when OFF; TIE shear boost is 1.0 when OFF (multiply by the exact literal 1.0f) — both paths byte-identical stock arithmetic when the toggle is off, and the toggle defaults OFF so a fresh install renders stock.

### Shrubs (Shrub renderer, vertex-stage displacement — shrub.vert)
- Time-driven sine keyed on world position: one coherent gust travelling across the field (spatial phase ~5.5 m wavelength, 0.24 Hz) on two decorrelated axes, plus a fine-scale shimmer (~0.4 m phase variation) so larger plants deform instead of translating rigidly.
- Per-PLANT base anchor + height normalization: a Wx1 RGBA8 LUT indexed by color_index (constant per shrub instance, extract_shrub assigns one palette slot per instance) stores 16+16-bit packed (minY, height) per plant, built once at level load in Shrub::update_load — roots stay planted, and a small bush and a tall kelp both reach full sway at their own crowns. Same device-proven Wx1 RGBA8 texelFetch pattern as the TOD LUT (no float textures on the Adreno path); texture freed in discard_tree_cache.
- Amplitude default 0.10 m at the crown (quadratic height ramp), live-tunable via prop `debug.opengoal.foliage.shrub_amp` / env FOLIAGE_WIND_SHRUB_AMP, clamped 0..0.3 m.

### Palm leaves (TIE renderer — Tie3.cpp; palms are jak1 TIE wind protos, tfrag untouched)
- jak1's stock TIE wind system is alive on Android (GOAL update-wind fills *wind-work* every unpaused frame; add-pc-wind-data DMAs it to the renderer). Census (new one-shot log): beach tree=0 wind_draws=5 wind_instances=64; village1 trees wind_instances=14+65.
- The sway boost (default 3.0x, prop `debug.opengoal.foliage.tie_mult` / env FOLIAGE_WIND_TIE_MULT, clamp 1..8) is applied ONLY to the matrix shear inside do_wind_math. Root-cause note: boosting `stiffness` (the obvious lever, tried first) is SELF-CANCELLING — the stiffness-scaled vf27 is persisted into the wind integrator state and feeds the cy=100 restoring term next frame, so the spring stiffens and visible sway barely changes (proven on device: 8x stiffness = zero visible delta). The shear-only boost leaves the integrator state stock.
