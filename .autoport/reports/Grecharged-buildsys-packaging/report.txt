== The owner's rule, implemented mechanically ==
Sort rule: a file ships in <game>_assets.zip iff a diff against the vanilla OpenGOAL pipeline output is
empty; everything port-modified/custom ships in the game package. Implemented as a CLASSIFIER, not a
hand list: an out/<game>/iso member is vanilla iff byte-identical to a file under iso_data/<game>/
(sha256 index); stock .fr3 are vanilla-derived, attested live by the producer (git diff 107f26a44..HEAD
of decompiler/level_extractor + decompiler/config must be EMPTY or the producer dies). Verified census:
out/jak1/iso = 321 files = 247 verbatim disc data (all byte-match iso_data) + 28 CGO/DGO (goalc, port)
+ 46 TXT banks (23 COMMON + 23 SUBTIT — carry custom text ids 1700-1713/16e, port). out/jak1/fr3 =
26 stock .fr3 (vanilla) + 2 .grassbake (port tool output).
