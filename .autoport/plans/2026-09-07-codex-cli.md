## Corrections révélées par les vérifications

- Les tests de migration passaient `--out /tmp/...`, mais le migrateur écrivait
  quand même cinq prompts dans le dépôt réel. Ils ont été restaurés à leur état
  initial (propres dans le premier git status). Les prompts de migration sont
  maintenant écrits à côté de --out, et le test vérifie leur non-modification.
- Les explications de refus de pre-tool.sh exécutaient pick_device.sh à cause
  d'une substitution shell dans le message. Elles affichent désormais la commande
  littérale, sans sonder un appareil. La règle de refus reste identique.
- Le watchdog de périmètre est maintenant vérifié aussi lorsque le flux JSON est
  continu ; une CLI bavarde ne peut plus masquer un changement de périmètre.
- Un échec d'exec ou un pipe stdin fermé avant consommation reste diagnostiquable.

## Limites et exploitation

- Aucun item du jeu ni démon de production n'a été lancé par cette adaptation.
  Les builds/APK et tests sur téléphone ne font pas partie du smoke de CLI.
- Le JSONL public Codex n'expose pas tous les appels de collaboration : le spawn
  réel est visible dans le transcript local, alors que le JSONL expose le wait.
  Le plafond d'appels observés n'est donc pas un plafond global de sous-agents
  ou de tokens. Il ne prétend pas équivaloir exactement à max-turns Claude.
- La veille ne réveille le modèle que si le digest change. La remise utilise un
  UUID exact enregistré au démarrage du superviseur, jamais --last. Sans thread
  enregistré elle reste en observation ; un échec de remise est retenté.
- Les contrats anciens contiennent encore des consignes Redmi-only contredites
  par la demande du 6 septembre et par pick_device.sh. Cette divergence est
  consignée dans le handoff, sans changer la politique d'appareils dans ce portage.
- Le mode autonome Codex a les mêmes besoins d'accès que le harnais Claude.
  Son profil est distinct ; il n'altère pas celui de Claude ni la configuration
  utilisateur de Codex. Les mécanismes imposés par l'environnement restent souverains.
