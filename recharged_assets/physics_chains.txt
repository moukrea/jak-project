# Grecharged-secondary-motion — data-driven chain params (hot-editable; adb push + toggle physics to reload)
# classes: primary=1 secondary=2 accessory=4 ; stiffness in Hz ; maxangle in degrees ; radius in game units (4096/m)
#
# CHAIN KEYS
#   stiffness damping gravity maxangle inertia stretch radius   (as before)
#   rootlock=N   the first N links ride the animated bone RIGIDLY — no integration, no cone, no
#                write-back. This is what keeps a hair chain's ROOT welded to the skull instead of
#                the whole strand floating free (owner cycle-2 defect B). Clamped to len-1, so a
#                single-joint chain is never fully frozen.
#   gradient=G   0 = uniform (pre-cycle-2), 1 = full root->tip freedom ramp: the first free link
#                keeps 1/nfree of the swing cone and is proportionally stiffer, the tip keeps the
#                full authored amplitude. Only meaningful with >=2 free links.
#   anim=MODE    what to do with the AUTHORED animation channel on a physics-owned joint. jak1
#                already hand-keys pseudo-wind on straps/hair/cloth, and springing toward that pose
#                left two motions fighting (owner cycle-2 defect A: Jak's blue cloth clipping —
#                shirtLthigh/shirtRthigh were replaying the driver's ENTIRE leg swing).
#                  replace (DEFAULT) — the joint is re-glued to its bind-pose local carried by the
#                    animated parent; the authored channel is dropped and physics owns the joint.
#                  excite  — same re-glue, but the dropped channel comes back as an input FORCE
#                    scaled by excite= (never a second writer). Use where the channel is ACTING
#                    rather than fake physics: Daxter's ears/tail, Samos' beard.
#                  keep    — pre-cycle-2 behaviour (spring toward the authored pose).
#   excite=X     force scale for anim=excite. 1.0 reproduces `keep` exactly, so the mode is monotone.
#   friction=F   0..1 contact friction: the collision push-out is absorbed into the verlet `prev`
#                instead of reading as free velocity next substep (kills contact buzz). Default 0.5.
#
# CYCLE-3 CHAIN KEYS (owner verdict 2026-08-06)
#   authored=T   AUTHORED ANIMATION HAS PRIORITY.
#                MEASURED LIMIT, READ THIS BEFORE ARMING A NEW CHAIN: T compares the authored pose
#                to the calm rest pose, so it also sees a STATIC pose offset — a character whose
#                idle simply holds a bone away from its bind pose reads as "the animator is driving
#                it" forever, and full suspension then deletes that chain's physics silently. Armed
#                cast-wide on every anim=excite chain, the x86 smoke measured exactly that:
#                Daxter's ears/tail sit at 0.53-1.36 of chain length CONTINUOUSLY and Samos' stock
#                beard at a flat 0.425 (holdmax 2697 frames = 45 s of unbroken suspension). So it is
#                armed ONLY where the owner named a discrete forced action, with a threshold above
#                that chain's MEASURED routine level. To arm another chain: read its `aratio:` in
#                the [HD-PHYS2] window line first, then pick a threshold above its routine peak —
#                the holdmax gate in physics_x86_smoke.sh fails the build if you get it wrong. T is the authored offset, as a fraction of the
#                chain's own length, at which ND is judged to be DRIVING these bones on purpose
#                (Jak's ears reacting, Keira GRABBING her goggles). Above T the sim hands the chain
#                over: the target becomes the authored pose, gravity/excitation fade out, collisions
#                stop. Below T/2 it takes it back, progressively. 0 = OFF, and 0 IS THE DEFAULT —
#                jak1's hand-keyed pseudo-wind would also cross a global threshold, and the owner's
#                cycle-2 verdict is that the wind stays removed. Opt in only where ND ACTS.
#   authrise=R   blend-in rate per second (how fast the animation takes over).
#   authfall=F   blend-out rate per second — this is the "physics resumes progressively" ramp.
#   authstiff=S  stiffness multiplier at full authored weight (how tightly the authored pose tracks).
#   rootfree=X   FLOOR of the root->tip freedom ramp, 0..1. Default 0.3. The raw ramp gives the
#                stiffest free link 1/nfree of the cone, which is right on an 8-link cape and
#                useless on a 2-link one — that is why Jak's coiffe and Keira's short back hair
#                both read as "only the very tip moves". Can only RAISE freedom, never lower it.
#   colskip=N    the first N links are INSIDE the body on purpose (a hair root is glued to the
#                skull) — exempt from collision push-out AND from the residual audit. Until cycle 3
#                this was an accident of rootlock=; freeing a root to MOVE without it would weld
#                every hair root against its own skull. Effective value is max(rootlock, colskip).
#   nodesc=1     do NOT rigid-re-glue this chain's descendants (they carry their own animation).
#
# CYCLE-3 COLLIDER KEY
#   radius2=R    FAR-END radius: the volume becomes a CONE instead of a cylinder, and the contact
#                radius is interpolated at the contact point. A constant radius cannot model a
#                FLARED trouser leg or a shoulder, which is why Jak's jacket hem clipped through a
#                capsule that was correctly sized for his thigh (owner cycle-3 C).
#
# TWO OWNER-LISTED SITES HAVE NO BONE TO DRIVE — documented, not dropped (see the phase report):
#   * Jak's metal RING on his chest-plate (owner cycle-3 E) and the metal BUCKLE on the strap in his
#     back (owner cycle-3 H). Neither jak-hd (75 joints) nor eichar-lod0 (83) has any ring/buckle/
#     plate/medal/pendant/clasp joint, and a scan of ALL 458 shipped rigs in
#     decompiler/config/jak1/ntsc_v1/joint-node-info.min.json returns zero hits game-wide. Both are
#     rigidly skinned to chest / packStrapMid. Giving them physics needs a bone INJECTED at HD prep
#     plus a weight transfer on the mesh — an asset-pipeline job, not a line in this file.
#
# COLLIDER KEYS  (owner 17:35: a REAL body volume, not 1-2 symbolic spheres)
#   collider <joint> radius=R [chains=a,b] [tier=N]          sphere on one animated bone
#   capsule  <jointA> <jointB> radius=R [chains=a,b] [tier=N] swept volume between two animated bones
#   tier: 1 = core (present at EVERY precision level that collides), 2 = extended. A level may thin
#   the set, never to the point of letting a chain pass visibly through the body.
#
# LEVEL KEYS: substeps iters classmask fixedhz, and `collide` = the max collider TIER (0 = none).
# Level 0 collides now (tier 1): the cheapest rung must still be CREDIBLE, and a chain sinking into
# the torso is not "cheap", it is broken.

# Grecharged-hd-eye-scale — HD CARTOON EYE-SIZE GAIN (owner 2026-08-06, "yeux trop globuleux").
# Read by EyeRenderer.cpp, not by the physics parser. Applies to HD-COVERED eye slots ONLY: a stock
# jak1 model always keeps jak1's exact channel, so ORIGINAL looks are bit-identical.
#
# jak1 changes eye size by scaling the iris/pupil sprite inside the character's 32x32 eye tile, and
# that scale is ABSOLUTE IN TILE SPACE (scale 1.0 = the sprite covers the whole tile). The HD donor
# eyeball wraps that same tile around a round eye where jak1's is a small flat patch, so an identical
# excursion reads far bigger on an HD head. These keys compress the excursion around the neutral;
# they never remove it.
#   on=0|1        1 = compress (default). 0 = raw jak1 channel on HD too (the pre-fix behaviour).
#   neutral=N     the authored rest value of the channel; the curve is an exact identity there, so
#                 the eye at rest is untouched. 1.0 is ND's own no-data default (eye.gc:952-959).
#   gainup=G      kept fraction of the ABOVE-neutral excursion — the one that bulges the eye.
#   gaindown=G    kept fraction of the BELOW-neutral excursion (eye shrinking).
# ------------------------------------------------------------------------------------------------
[eyescale]
on=1 neutral=1.0 gainup=0.45 gaindown=0.70
