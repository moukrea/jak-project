# water_falls.txt — LE VERDICT DE CHAQUE PROTOTYPE TIE/TFRAG QUI PORTE UNE TEXTURE DE LIQUIDE.
# Item `water-census` (SPEC-refonte-eau.md §5.7, §5.8). Genere depuis les 26 .fr3 par
# `tools/water_bake`, puis TRANCHE A LA MAIN, une ligne par nom. Format de la SPEC §5.7 :
#
#   CHUTE  <proto>  dir=<x,y,z> vitesse=<m/s> bandes=<n> impact=<x,y,z> r=<m> force=<0..1> brume=<groupe>
#   JET    <proto>  impact=<x,y,z> r=<m> periode=<s>
#   NAPPE  <proto>  matiere=<mer|riviere|mare|boue|eco|lave|electrique>
#   EXCLU  <proto>  <raison>
#
# Les champs numeriques des lignes CHUTE et JET valent `?` : ils sont la charge utile de l'item
# `water-falls` (SPEC §9 item 7), pas de celui-ci. Un `?` est un inconnu DECLARE, pas un implicite.
#
# AUCUN IMPLICITE. Les 196 noms recenses par water_bake ont chacun leur ligne. Un nom absent de
# ce fichier est compte dans `water_proto_unassigned`, la porte de l'item.
#
# COMMENT LES CANDIDATS SONT TROUVES, ET POURQUOI IL Y A 165 `EXCLU`.
# ------------------------------------------------------------------
# `TFragmentTreeKind::WATER` existe dans le format fr3, et il est VIDE sur les 26 niveaux de
# jak 1 : `tfrag_water_trees=0` partout (water_inventory.txt). Le signal de donnee que ND aurait
# pu nous donner n'existe pas ici. Il ne reste que le NOM, et water_bake le cherche LARGEMENT.
#
# Or les prefixes de niveau `lava-` (lavatube) et `swp-` (swamp) sont eux-memes des mots du
# lexique : 243 des 268 textures de lavatube « matchent ». L'asymetrie est assumee — un candidat
# de trop coute une ligne `EXCLU` a ecrire, un candidat manquant sort du denominateur SANS QUE
# RIEN NE LE DISE et rend la porte verte par inaction. D'ou 165 `EXCLU`, chacun avec sa raison.
#
# CE QUE LA TABLE DES TEXTURES NE SUFFIT PAS A TRANCHER. « Toutes ses textures sont liquides »
# est un critere SEDUISANT ET FAUX : `lava-stalactite-02.mb` n'habille que `lava-ground` et reste
# de la roche ; `vil3-metal-pins.mb` n'habille que `vil3-sulfurpool-center` et reste du metal.
# Le nom tranche, la table de textures sert de PREUVE, et chaque cas limite porte sa raison.
#
# TROUVAILLE A REMONTER A L'ITEM `water-falls` : sur les 196 noms, DEUX seulement sont des
# chutes, et les deux sont de la LAVE. Aucune nappe de cascade d'EAU n'existe dans la geometrie
# de niveau de jungle, village2, training ni beach — ce que la SPEC §2.4 annonce (« la nappe est
# de la geometrie de niveau ») est vrai pour la lave et FAUX pour l'eau : les chutes d'eau de
# jak 1 sont des groupes sparticle devant une paroi, et rien d'autre.
#
